# 海盗骰子（局域网多人版）

一个基于浏览器和 WebSocket 的局域网多人骰子游戏。玩家可创建或加入六位数字房间，实时查看房间人数、其他玩家的投掷状态、剩余骰子和金币数。

## 功能

- 创建或加入六位数字房间
- 最多支持 8 名玩家
- 每位玩家拥有 6 个骰子
- 投掷动画和实时游戏状态同步
- 金币与骷髅骰子判定
- 玩家金币排行榜
- 玩家名称保存到浏览器本地存储
- 离开房间或断开连接后自动清理玩家状态
- 响应式页面，支持手机和桌面浏览器

## 游戏规则

- 每轮投掷当前仍然有效的骰子。
- 投掷结果为金币时，玩家获得 1 枚金币，骰子继续保留。
- 投掷结果为骷髅时，该骰子失效。
- 当 6 个骰子全部失效时，游戏结束。
- 点击“重新开始”可恢复 6 个骰子并将金币和轮次清零。
- 金币数在房间内实时广播并更新最高记录和排行信息。

## 环境要求

- Node.js 18 或更高版本
- 支持 WebSocket 的现代浏览器
- 使用局域网游玩时，所有设备需连接到同一网络

## 安装

在项目目录中执行：

```bash
npm install
```

也可以使用已包含的依赖锁文件进行安装：

```bash
npm ci
```

## 启动

```bash
npm start
```

服务默认监听端口 `3000`。启动后访问：

- 本机：<http://localhost:3000>
- 局域网：<http://服务器设备的局域网IP:3000>

服务器启动时会尝试输出本机 IPv4 地址。例如：

```text
http://192.168.1.100:3000
```

若无法从其他设备访问，请检查防火墙是否允许入站 TCP 连接，或确认所有设备在同一局域网。

## 使用方法

1. 在浏览器中打开服务地址。
2. 输入玩家名称。
3. 点击“创建房间”，系统会生成六位数字房间号。
4. 将房间号和局域网地址发送给其他玩家。
5. 其他玩家输入名称和房间号后点击“加入房间”。
6. 房间中最多可容纳 8 名玩家。
7. 点击自己的“投掷骰子”按钮开始游戏。

## 技术栈

- HTML、CSS 和原生 JavaScript
- Node.js `http` 模块
- [`ws`](https://github.com/websockets/ws) WebSocket 服务
- 浏览器 `localStorage` 和 `WebSocket` API

## WebSocket 消息类型

服务端和客户端主要通过以下消息进行通信：

| 消息类型 | 说明 |
| --- | --- |
| `PLAYER_JOIN` | 玩家加入房间 |
| `PLAYER_LEAVE` | 玩家主动离开或断开连接 |
| `PLAYER_UPDATE` | 同步投掷结果、金币和游戏状态 |
| `ROOM_PLAYERS` | 向新玩家发送房间内玩家列表 |
| `MAX_SCORE_UPDATE` | 广播最高金币数及持有人 |
| `PING` / `PONG` | 心跳检测 |
| `ERROR` | 房间已满或其他错误提示 |
